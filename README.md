# Titanic - Machine Learning from Disaster

Este repositório tem como objetivo documentar minha evolução em Análise de Dados e Machine Learning por meio da participação em uma das competições mais conhecidas do Kaggle.
A proposta é refazer a solução desse desafio do zero a cada semestre, aplicando novos conhecimentos, técnicas e boas práticas adquiridas ao longo do tempo. Dessa forma, consigo acompanhar minha evolução, identificar pontos de melhoria e comparar abordagens utilizadas em diferentes momentos da minha jornada na área de dados.
